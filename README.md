# CBH Viewer – Releases

Fertige APKs der Android-App **CBH Viewer** (ChessBase-Datenbanken und PGN lesen, Analyse mit Stockfish 19).
Der Quellcode liegt in einem privaten Repository; hier liegen nur die installierbaren Versionen.

Die App prüft beim Start selbst, ob hier eine neuere Version liegt, und bietet die Installation an.
Manuell: unter [Releases](https://github.com/royalprobe/cbhviewer-releases/releases) die neueste `.apk` herunterladen und öffnen.

Enthält Stockfish 19 (GPLv3, Quellcode: https://github.com/official-stockfish/Stockfish).
